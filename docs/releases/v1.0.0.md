# run-design-sprint v1.0.0

`v1.0.0` is the initial stable release of Design Sprint for One. It packages a
resumable, evidence-led one-human-plus-AI sprint workflow with explicit human
decision gates, bounded specialist roles, deterministic accessible HTML, and
strict privacy and customer-evidence boundaries.

## Highlights

- Sprint-book and adaptive profiles with live, self-test, and
  planning/rehearsal modes.
- Explicit route, method-fidelity, evidence-strength, decision-readiness, and
  terminal-state reporting.
- Dependency-free workspace creation, protected migration, schema validation,
  deterministic rendering, portable site export, and publication checks.
- Versioned assignment provenance, prototype/test-artifact lifecycle, isolated
  customer sessions, practical recruitment planning, and reproducible usage
  reporting.
- Formal compatibility, support, deprecation, contribution, security, and
  release policies plus clean public installation verification.

## Install

```bash
npx --yes skills@1.5.22 add \
  "https://github.com/Ty-Robb/sprint.git#v1.0.0" \
  --skill run-design-sprint \
  --agent codex \
  --copy \
  --yes
```

This installer path is verified on Node.js 22 and 24. The installed runtime
uses only Python's standard library and supports Python 3.10-3.14 on Ubuntu
24.04, macOS 14+, and Windows Server 2022+.

## Workflow and schema compatibility

The release uses method profiles `1.0`, progressive step guidance `1.0`,
fidelity records `1.0`, role packets `1.0`, and test-artifact workflow `1.0`.
The current major persisted families are:

| Family | Current | Migratable legacy versions |
|---|---:|---|
| Workspace state | `4.0` | `1.0`, `2.0`, `3.0` |
| Artifact data | `3.0` | `1.0`, `2.0` |
| Session manifest | `2.0` | `1.0` |
| Customer-session record | `2.0` | `1.0` |

All other schema families are current-only at the versions recorded in
[`release-contract.json`](../../skills/run-design-sprint/references/release-contract.json).
Readers do not silently accept legacy or unknown versions. Preview protected
migrations with:

```bash
python3 <skill-dir>/scripts/sprint_workspace.py migrate \
  --workspace <sprint-directory> \
  --dry-run
```

There is no earlier tagged release. Untagged legacy workspace state and artifact
data can be migrated only when their versions are listed above; session 1.0
migration conservatively requires evidence-quality reassessment.
